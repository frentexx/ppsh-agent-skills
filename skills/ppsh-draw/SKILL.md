# AI 生圖（ppsh-draw）

## 先搞清楚：你真的需要這個技能嗎？

| 你想做的事 | 該用什麼 | 要錢嗎 |
|---|---|---|
| 把一份要點做成**一張圖看完**的圖卡 | `ppsh-soil-infographic` | **免費** |
| 做**簡報**（可編輯 .pptx） | `ppsh-soil-teaching-deck` | **免費** |
| 做**簡報**（可分享連結 .html） | `ppsh-soil-html-deck` | **免費** |
| 要一張**AI 畫出來的插圖／封面** | 本技能 | 💰 要 |

> **資訊密集的內容不要用 AI 生圖。** 中文字在生圖模型裡常常會糊掉或變亂碼，
> 要文字精準就用上面三個技能（純向量排版，改一個字只要 3 秒）。
> AI 生圖適合的是**氛圍、插畫、封面主視覺**這類不靠文字傳達的東西。

## 不花錢的替代方案（先講這個）

要 AI 插圖但不想付費，**不需要這個技能**：

1. 用學校 Google 帳號打開 [aistudio.google.com](https://aistudio.google.com) 或 Gemini App
2. 在網頁上生圖（網頁介面有免費額度）
3. 存成檔案，自己放進簡報

**網頁免費、API 要錢**，這兩件事常被搞混。

## 要用 API 的話：設定金鑰

本技能只走 Google Gemini（老師手上最容易申請到的一家）：

| 供應商 | 金鑰變數 | 說明 |
|---|---|---|
| Google Gemini | `GEMINI_API_KEY` | ⚠️ **生圖模型不在免費層**，專案必須先開啟帳單。免費 key 打下去會回 **429**（配額 0），那不是金鑰壞掉 |

金鑰寫進檔案，**不要貼進對話、不要寫進任何會同步到雲端的資料夾**：

```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude\_secrets" | Out-Null
# 用記事本自己貼進去，不要在對話裡輸入金鑰
notepad "$env:USERPROFILE\.claude\_secrets\GEMINI_API_KEY.key"
```

## 用法

先確認這台機器能不能生圖（**只讀，可直接執行**）：

```powershell
python -X utf8 "<技能資料夾>\ppsh-draw\draw.py" --probe
```

| 結果 | 意思 |
|---|---|
| 印出 `gemini`（離開碼 0） | 可以生圖 |
| 印出 `[no-key]`（**離開碼 3**） | 這台機器沒設定生圖。**停下來回報老師**，不要重試 |

生圖：

```powershell
python -X utf8 "<技能資料夾>\ppsh-draw\draw.py" "一隻穿西裝的龍蝦，扁平向量插畫風" --size 1024x1024 --name lobster
```

| 參數 | 說明 |
|---|---|
| `--size` | `1024x1024`（方）、`1536x1024`（16:9 橫）、`1024x1536`（直） |
| `--n` | 張數，預設 1 |
| `--name` | 檔名前綴 |
| `--outdir` | 輸出資料夾，預設 `./slides/generated/` 或 `./generated/` |

## 提示詞的三個雷區

1. **別叫它寫中文字**——會糊掉或變亂碼。要有字就寫 `No readable text`，文字自己用排版加上去
2. **留白要講明**——例如「下方留出深色純色區供文字疊加」，不然字會壓在主體上看不清
3. **風格詞要統一**——同一份簡報所有圖用同一串風格描述，否則每張長得不像一套

## 安全

- 生圖提示詞會送到外部服務。**公文全文、學生個資、含個資的圖片一律不要送**。
- 這個技能只會寫入你指定的輸出資料夾，不改任何既有檔案。
