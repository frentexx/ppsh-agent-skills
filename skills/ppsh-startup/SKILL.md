# 開工（屏北高中版）

目的：老師在**任何一台電腦、任何一個新對話**坐下來，30 秒內知道上次做到哪、現在該做什麼。

## 步驟

### 1. 找到專案

看目前工作資料夾有沒有 `AGENTS.md`。

- **有** → 就是這個專案
- **沒有** → 往上一層找一次
- **還是沒有** → 告訴老師「這個資料夾還沒初始化」，問要不要先說「初始化專案」（`ppsh-project-init`）。**不要自己編一份。**

### 2. 只讀兩份檔案

- `AGENTS.md` → 目的、時程、注意事項
- `handoff.md` → 上次做到哪、下一步、卡關

**只讀這兩份，不要一開場就掃整個資料夾**——那會把桌面（上下文）塞滿，又幫不上忙。

### 3. 檢查是不是換了電腦

比對 `handoff.md` 的「最後更新」電腦名稱與目前這台（執行 `hostname` 取得，Windows 與 macOS 都能用）。

**不同台** → 明確說「上次是在 <某台> 做的」，並提醒：
「請先確認 Google 雲端硬碟已同步完成（檔案總管或 Finder 裡的檔案圖示是綠色勾勾），不然讀到的可能是舊版。」

同一台就不用提。

### 4. 看時程有沒有逼近

對照 `AGENTS.md` 的時程表與今天日期，**7 天內到期且未完成**的節點主動提出來。

### 5. 回報（簡短）

```
專案：<名稱>
上次：<電腦名稱>，<日期>
做到：<一兩句>
下一步：
  1. <動作>
  2. <動作>
卡關：<有才寫>
時程提醒：<7 天內到期的節點，沒有就省略>
```

回報完**停下來等老師指示**，不要自動開始做下一步。

## 不要做的事

- 不要修改任何檔案（開工只讀）
- 不要執行 git 指令
- 找不到 `handoff.md` 時不要自己編，改建議先初始化

## 相關技能

- 初始化：`ppsh-project-init`
- 收工：`ppsh-shutdown`
