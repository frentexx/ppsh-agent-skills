# 專案初始化（屏北高中版）

為一個專案資料夾建立兩份純文字檔：

| 檔案 | 用途 | 比喻 |
|---|---|---|
| `AGENTS.md` | 專案藍圖：目的、產出、時程、注意事項 | 班級經營計畫 |
| `handoff.md` | 交接檔：上次做到哪、下一步 | 代課交接本 |

以後老師說「開工」，就讀這兩份接續；說「收工」，就更新它們。

**這個技能不碰 git，也不上傳任何東西。** 跨電腦同步靠 Google 雲端硬碟電腦版，存檔即同步。

## 1. 先確認資料夾

1. 以**目前的工作資料夾**當專案資料夾，把完整路徑念給老師確認。
2. 檢查路徑是否在 Google 雲端硬碟底下（路徑含 `我的雲端硬碟`、`My Drive`、`共用雲端硬碟`、`Shared drives`，或是雲端硬碟電腦版的磁碟代號如 `G:\`）。
   - **在** → 繼續。
   - **不在** → 提醒一句：「這個資料夾不在 Google 雲端硬碟，換電腦時會接不到。要繼續嗎？」老師說繼續就繼續，**不要自己搬資料夾**。
3. 檢查是否已經有 `AGENTS.md` 或 `handoff.md`。**有的話絕對不要覆蓋**，改問老師：要「更新內容」還是「保留不動」。

## 2. 訪談（一次問完，不要一題一題來回）

用一則訊息問完下面四題，老師沒答的就先寫「待補」：

1. 專案名稱，和一句話說明要做什麼
2. 主要產出是什麼（例：考卷、學習單、簡報、成績分析、活動計畫）
3. 有沒有期限或重要日期
4. 有沒有相關的雲端檔案要記下位置（例：共用試算表、表單）

> ⚠️ 不要把學生姓名、學號、成績、聯絡電話寫進這兩份檔案。需要提到學生時，用「班級＋座號」。

## 3. 建立 AGENTS.md

寫在專案資料夾根目錄，UTF-8 編碼：

```markdown
# <專案名稱>

> <一句話目的>
> 建立日期：YYYY-MM-DD

## 產出
- <主要交付物>

## 時程
| 節點 | 日期 | 狀態 |
|------|------|------|
| <節點> | <日期或待補> | ⬜ |

## 資料夾結構
<只列有意義的層級；剛建立時寫「待補」即可>

## 環境與工具
- 讀取 PDF／Word／PowerPoint／Excel：`ppsh-office-reader` 技能（若已安裝）

## 對照表
| 類型 | 位置 |
|------|------|
| 專案資料夾 | <完整路徑> |
| 相關雲端檔案 | <網址或待補> |

## 注意事項
- 學生資料一律去識別化（班級＋座號），不寫姓名
- <這個專案特有的規則>
```

## 4. 建立 handoff.md

同樣寫在專案資料夾根目錄：

```markdown
# 交接檔：<專案名稱>

**最後更新**：YYYY-MM-DD HH:MM ｜ <電腦名稱>

## 上次做到哪
專案剛初始化，尚未開始。

## 下一步
1. <從訪談答案推出第一個可以直接動手的動作>

## 卡關／待決
無

## 變更紀錄
- YYYY-MM-DD <電腦名稱>：初始化專案
```

時間與電腦名稱**一定要實際執行指令取得**，不可以寫「待補」：

| 要取得 | 指令（PowerShell、命令提示字元、macOS 終端機都能用） |
|---|---|
| 電腦名稱 | `hostname` |
| 現在時間 | PowerShell：`Get-Date -Format "yyyy-MM-dd HH:mm"`；macOS／bash：`date "+%Y-%m-%d %H:%M"` |

## 5. 完成回報

```
專案初始化完成
  專案資料夾：<完整路徑>
  已建立：AGENTS.md、handoff.md
  雲端硬碟：<在／不在（已提醒）>
  下一步：<handoff.md 的第一項>
  → 以後說「開工」我會讀這兩份檔案；說「收工」我會更新它們
```

## 不要做的事

- 不要覆蓋已存在的 `AGENTS.md`、`handoff.md`
- 不要執行 git init、不要建 GitHub repo、不要上傳
- 不要搬動或刪除老師的任何檔案

## 相關技能

- 開工：`ppsh-startup`
- 收工：`ppsh-shutdown`
