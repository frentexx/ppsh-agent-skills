# 收工（屏北高中版）

目的：把今天的進度寫成**下一次（或另一台電腦）30 秒看得懂的交接**。

**這個技能不碰 git，也不上傳任何東西。** 跨電腦同步靠 Google 雲端硬碟電腦版。

## 步驟

### 1. 找到專案

找目前工作資料夾（或往上一層）的 `AGENTS.md`。找不到就問老師專案在哪，**不要自己建新的**。

### 2. 回顧這次做了什麼

根據**這次對話的實際內容**整理，不要反問老師「你今天做了什麼」——你自己知道。

整理成三件事：
- 完成了什麼（具體到檔案名稱）
- 還沒完成、做到一半的
- 發現的問題或要老師決定的事

### 3. 更新 AGENTS.md（只在真的有變動時）

- 時程表的狀態欄（⬜ → ✅）
- 資料夾結構（新增了重要資料夾時）
- 注意事項（發現新的雷點時）

沒變動就**不要動**這個檔案。

### 4. 改寫 handoff.md（整份重寫，不是往下追加）

追加會越積越長，接手的人不知道看哪段。

- **最後更新**：現在時間＋電腦名稱（Windows：`$env:COMPUTERNAME`；macOS：`scutil --get ComputerName`）
- **上次做到哪**：具體。寫「第 2 回學習單完成 1–8 題，卡在第 9 題的圖」，不要寫「處理了一些資料」
- **下一步**：1–3 項，寫成**可以直接動手的動作**
- **卡關／待決**：等人回覆、等老師決定的事；沒有就寫「無」
- **變更紀錄**：最上面加一行今天的，**只保留最近 5 筆**

### 5. 個資與金鑰提醒

掃一下這次有沒有產生或寫入：
- 學生姓名、學號、身分證字號、電話、成績 → 提醒去識別化（只留班級＋座號）
- API 金鑰、密碼、token → 提醒不可放在會同步到雲端的檔案

沒有就不用講。

### 6. 回報並提醒同步

```
收工完成
  AGENTS.md：<已更新／無變動>
  handoff.md：已更新（<電腦名稱>）
  完成：<一兩句>
  下次接手：<下一步第一項>
  提醒：<個資或金鑰，沒有就省略>
  → 離開前請確認 Google 雲端硬碟同步完成（綠色勾勾）
```

## 不要做的事

- 不要執行 git commit／push
- 不要把 `handoff.md` 寫成流水帳，它是給人 30 秒讀完的
- 不要刪除或搬動老師的檔案
